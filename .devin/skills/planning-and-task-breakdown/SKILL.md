# Planning and Task Breakdown

## Process
1. **Understand Goal**: desired outcome, constraints, definition of done
2. **Decompose into Milestones**: independently valuable deliverables
3. **Break into Tasks**: 1-4 hours each, clear acceptance criteria
4. **Identify Dependencies**: blockers, parallelizable items
5. **Estimate & Prioritize**: S/M/L sizing, MoSCoW prioritization

## Task Quality Checklist
- Single clear objective
- Verifiable acceptance criteria
- No hidden dependencies
- Completable in one session
- Clear done state

## Anti-Patterns
- Tasks too large ("Implement the backend")
- No acceptance criteria
- Missing dependencies
- No priority ordering
