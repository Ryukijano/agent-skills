Forecast eruption probability by fusing seismic, gas, and satellite data to issue early warnings at volcanoes like Whakaari.

## Trigger

When the user is working on or asking about `ai for volcanology`.

1. Load the `ai-for-volcanology` skill for the full reference.

3. Propose the smallest verification or code snippet they can run next.
4. Point them at the references and any relevant `cuda-blackwell-labs` or `agent-skills` examples.
