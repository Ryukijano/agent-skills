# PRISMA 2020 Checklist (Abbreviated)

Use when finalizing a systematic review. Mark each item: ✅ done, ⚠️ partial, ❌ N/A.

## Title & Abstract

- [ ] Identify as systematic review in title
- [ ] Structured abstract: background, objectives, sources, eligibility, methods, results, conclusions

## Introduction

- [ ] Rationale for review
- [ ] Objectives with PICO/elements

## Methods

- [ ] Eligibility criteria specified
- [ ] Information sources listed (all databases, dates)
- [ ] Search strategy presented (full queries in appendix)
- [ ] Selection process described (screening stages, reviewers)
- [ ] Data collection process and extraction form
- [ ] Data items and outcomes defined
- [ ] Risk of bias assessment method
- [ ] Effect measures defined
- [ ] Synthesis methods (narrative, meta-analysis)
- [ ] Protocol registration (PROSPERO/OSF if applicable)

## Results

- [ ] PRISMA flow diagram with counts at each stage
- [ ] Study characteristics table
- [ ] Risk of bias results per study
- [ ] Synthesis results per outcome
- [ ] Reporting biases assessed

## Discussion

- [ ] Summary of evidence
- [ ] Limitations (studies and review process)
- [ ] Conclusions linked to objectives

## Other

- [ ] Funding and conflicts declared
- [ ] Data availability statement

## Screening Reason Codes

| Code | Meaning |
|------|---------|
| `E1` | Wrong population |
| `E2` | Wrong intervention/exposure |
| `E3` | Wrong outcome |
| `E4` | Wrong study design |
| `E5` | Not empirical / no data |
| `E6` | Duplicate |
| `E7` | Language / access |
| `E8` | Out of date range |
