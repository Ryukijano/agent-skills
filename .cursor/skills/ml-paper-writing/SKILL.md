# ML Paper Writing

## Paper Structure
1. Abstract (150-250 words): problem, approach, result, impact
2. Introduction: motivation, contribution, roadmap
3. Related Work: position in literature
4. Method: approach, architecture, formulation
5. Experiments: setup, baselines, metrics, results
6. Analysis: ablations, discussion, limitations
7. Conclusion: summary, future work

## Best Practices
- One idea per paragraph
- Active voice, present tense for facts, past for experiments
- Define notation on first use
- Forward-reference sections

## LaTeX
- NeurIPS: neurips_2026.sty, ICML: icml2026.sty, ICLR: iclr2026_conference.sty
- Use BibTeX, verify every citation
- \\citep for parenthetical, \\citet for textual

## Pitfalls
- Overclaiming without proof
- Missing ablations
- Unclear metrics
- No statistical significance
- No limitations section
