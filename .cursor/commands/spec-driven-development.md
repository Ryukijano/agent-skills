# Spec Driven Development

Guides agents through spec-driven development: write a spec, plan from it, generate tasks, implement incrementally. Use when starting a new feature needing clear requirements.

Skill: `.cursor/skills/spec-driven-development/SKILL.md`

## Workflow
1. Read `.cursor/skills/spec-driven-development/SKILL.md`
2. Identify requirements
3. Follow instructions
4. Verify and report
