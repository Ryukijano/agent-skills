# Research Strategy Run

1. List candidate ideas; score novelty/feasibility/impact/learning/fit 1-5 each.
2. Pick Pareto front, not max-novelty point.
3. For the chosen one: write hypothesis as "If X under Y then Z, measured by M" — metric defined BEFORE any run.
4. Set kill criteria now: time-box + metric-box. Write them down.
5. Define minimal viable experiment (smallest run proving/disproving core hypothesis).
6. Milestone ladder: smoke → pilot → full+ablation → robustness.
7. Fill risk register with mitigations; revisit at each milestone.

Apply `research-strategy-project-design`, `gap-to-topic`, `experiment-protocol`.
