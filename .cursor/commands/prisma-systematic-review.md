# PRISMA Systematic Review Run

1. Protocol: define PICO/SPIDER; write inclusion/exclusion criteria BEFORE searching; pre-register in protocol.md.
2. Search: Boolean queries per database (arXiv, Semantic Scholar, PubMed, IEEE Xplore); log query/date/db/raw-hits in search-log.md.
3. Screen titles/abstracts against criteria; record exclusions with reasons.
4. Full-text screen remaining; log exclusions.
5. Extract data into structured table (double-check numbers vs source).
6. Synthesize findings + PRISMA flow diagram with exact counts per phase.

Apply `prisma-systematic-review`, `literature-triage-matrix`.
