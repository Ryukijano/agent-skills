ArXiv search, paper digestion, BibTeX management, experiment tracking, and Semantic Scholar. Use when searching for papers, managing citations, creating experiments, or tracking research.

Skill: `.cursor/skills/research-workflow/SKILL.md`

## Workflow
1. Read `.cursor/skills/research-workflow/SKILL.md`
2. Identify which tool you need from the 8 available
3. Run the tool in CLI mode or invoke via MCP
4. Verify and report results
