# Scientific Research & Companion Blog Writer Run

1. Lock the **Contribution Triad** (*Precise Bottleneck* + *Core Mechanism* + *Decisive Ablation*) and draft the 5-sentence Abstract (context, mathematical/physical bottleneck, mechanism, quantified empirical proof, artifact release).
2. Design the **Visual Inverted Pyramid (Figure 1 Hero Teaser)**: Panel A showing the prior paradigm's failure mode; Panel B showing the proposed mechanism and Pareto win, paired with a self-contained 3-part caption (*What is shown*, *How to read it*, *Takeaway*).
3. Draft the **Dialectical Introduction & Related Work**: group prior literature into competing paradigms with charitable strengths and structural trade-offs—ban chronological `"Author (Year) did X"` laundry lists.
4. Enforce **Bijective Mathematical Notation**: maintain a strict 1-to-1 symbol-to-concept ledger, state plain-English intuition before each equation, and specify tensor shapes (`(B, T, D)`) and complexity immediately after.
5. Structure **Question-Driven Ablations & Calibrated Limitations**: title each analysis subsection as a falsifiable scientific question, build a cumulative ablation ladder table (`± std`, compute/latency column), and explicitly document breakdown regimes.
6. If generating a **Google Research-style companion post**, convert the Abstract into a 3-bullet TL;DR, replace Related Work with a visual paradigm contrast, and conclude with Quick Links + BibTeX.

Apply `scientific-research-writer`, `deep-tech-blog-writer`, `latex-paper-writer`, `claim-verification`.
