# Publishing & Peer Review Run

1. Identify mode: cover letter / rebuttal / review-response / resubmission.
2. Rebuttal: build concern→response→location table covering EVERY reviewer point; quote verbatim before answering.
3. Prefer new experiments over arguments; run quick ablations if <1 day.
4. Concede correct points explicitly; never defensive tone.
5. Double-blind sweep: third-person self-cites, strip PDF metadata (`exiftool -all=`), acks, repo URLs.
6. When reviewing: confidentiality, evidence-anchored judgments, declare conflicts.

Apply `publishing-and-peer-review`, `manage-submission`.
